# 🌿 Floravia

An academic full-stack e-commerce web platform dedicated to the sale of floral arrangements, plants, bonsais, and seeds.

This project is built from scratch as a learning endeavor to master client-server architecture, relational databases, and Human-Computer Interaction (HCI) principles.

## 🚀 Tech Stack

*   **Frontend:** React, TypeScript, Vite (focused on UI/UX and HCI standards)
*   **Backend:** C#, ASP.NET Core Web API
*   **Database:** Relational database managed via Docker
*   **Tools & DevOps:** Git, GitHub, Docker

## 🎯 Project Goals

*   Build a scalable RESTful API from the ground up using .NET.
*   Design and implement an intuitive, user-friendly interface following HCI guidelines.
*   Manage data persistence using Entity Framework Core.
*   Apply version control best practices and agile methodologies.

## 📦 Structure

The repository will be structured into two main environments:
1.  **Frontend:** Client interface, state management, and user interaction.
2.  **Backend:** Business logic, API endpoints, and database connection.
